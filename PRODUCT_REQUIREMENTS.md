# Product Requirements - Design System & UI

## 1. Authentication Pages (Login & Register)

### 1.1 Layout & Responsiveness
- **Big Screens (Desktop)**: 3:7 ratio (30% left panel, 70% right panel).
- **Medium Screens (Tablet)**: 4:6 ratio (40% left panel, 60% right panel).
- **Mobile**: Single column layout (stack).

### 1.2 Color Palette
- **System**: Must use the defined `auth` design system tokens.
- **Left Panel Background**: `auth.sidebar` (#002E25)
- **Left Panel Text**: `auth.sidebar-foreground` (#FFFFFF)
- **Right Panel Background**: `auth.card` (#FBF9F0)
- **Accent Color**: `auth.accent` (#4CD964)
- **Accent Text/Foreground**: `auth.accent-foreground` (#002E25)

### 1.3 Components
- **Inputs**: Rounded, semi-transparent background on dark panels.
- **Buttons**: Rounded, accent color primary actions.
- **Icons**: Consistent stroke width and styling.

### 1.4 Typography
- **Headings**: Serif font for main marketing copy.
- **Body**: Sans-serif for UI elements.
